# Group Podcast Project

Overview
This project was developed as part of a group coursework for a computer science module. The aim was to create a podcast exploring a relevant topic in computing, demonstration research, communication, and teamwork skills.

Project Description
our group worked collaboratively to plan, research, and produce a podcast episode. The project involved selecting a topic, gathering information, structuring discussion points, and recording the final podcast.

Features
- Well-researched podcast topc related to Computer Science
- Clear structured with introduction, discussion, and conclusion
- Team collaboration and shared responsibilities
- Use of digital tools for recording and editing 

Technologies Used 
- Audio recording software
- Online research resources
- GitHub for project documentation

My Contribution
I contributed to:
- Researching the podcast topic
- Planning discussion points
- Participating in recording the podcast
- Collaborating with the team members to organise and improve the content

How to Access the Project
- The podcast recording can be accessed via the submitted coursework files or shared platform (e.g. Blackboard)

Learning Outcomes 
Through this project, I developed:
- Communication and presentation skills
- Research and critical thinking
- Teamwork and Collaboration
- Confidence in discussing technical topics
